# ฮูกติวครู 🦉

เว็บแอปฝึกทำข้อสอบใบประกอบวิชาชีพครู “วิชาครู” สำหรับใช้ในครอบครัว

- สมัครด้วยชื่อผู้ใช้ + รหัสผ่าน (Firebase Authentication)
- คลังข้อสอบ 5 ด้าน นำเข้าจากไฟล์ .xlsx ได้ / มีชุดตัวอย่าง 150 ข้อ
- จำลองสอบจริง 100 ข้อ, สุ่มฝึกตามใจ, ฝึกข้อที่เคยผิด, ชุดข้อสอบสำเร็จรูป
- ตั้งเวลาได้ · โหมดสอบ/โหมดฝึก · เฉลยพร้อมเหตุผล
- แดชบอร์ดพัฒนาการ เรดาร์ 5 ด้าน คาดการณ์คะแนน และกลยุทธ์แนะนำ

## ตั้งค่า Firebase (ครั้งเดียว)
1. Authentication → Sign-in method → เปิด **Email/Password**
2. Authentication → Settings → Authorized domains → เพิ่มโดเมน GitHub Pages (เช่น `yourname.github.io`)
3. Firestore Database → สร้างฐานข้อมูล → แท็บ Rules → วางเนื้อหาไฟล์ `firestore.rules` → Publish
4. เปิดเว็บ สมัครบัญชีแรก (บัญชีแรก = ผู้ดูแลระบบ)

ไฟล์ทั้งหมดอยู่ใน `index.html` ไฟล์เดียว
